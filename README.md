# How Geographically Based Are You (Country Guessing Game)



Authors: Ali Ibraheem, Yu Xuan Diong, Yun Jie Foo



This is a game where you guess the country based on hints generated by a local LLM!



Region Selection:

Players may select from the "Europe" or "Asia" region for a localized experience! Countries in the region are not exhaustive.



Types of hints:

Players have a hint budget of 6 points per round. Random hints cost 1 point, and customized hints costs 2.



Random hint: Generate a random hint with the LLM about the country in question. Cost: 1 budget point



Customized hint: Ask the LLM a question about the secret country to guess it! Cost: 2 budget points



Statistics:

After each game of five rounds, players will be shown the statistics of their overall guesses and performance. The fewer hints and attempts used for each round, the better the quality score!
